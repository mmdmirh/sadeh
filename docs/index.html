Key Features

Enterprise Conversational AI

Advanced multi-model conversation system with context awareness and memory. Supports interactions with multiple AI models through an intuitive chat interface with threaded conversation history.

  • Context-aware conversations with memory
  • Multi-model support with model switching
  • Conversation history and thread management

Document Intelligence (RAG)

Powerful Retrieval-Augmented Generation capabilities with document processing and knowledge extraction. Upload, process, and query documents to get AI-enhanced responses based on your data.

  • Document indexing and semantic search
  • Knowledge extraction and contextualization
  • Document-grounded AI responses

Enterprise Security & Access Control

Comprehensive Role-Based Access Control (RBAC) system for pages, features, and AI models. Secure authentication and granular permission management for enterprise use.

  • Managed page and model permissions
  • Role-based feature access control
  • Secure user authentication system

Voice Interaction

Seamless voice recording and text-to-speech capabilities for hands-free AI interaction. Record voice messages and receive spoken responses through advanced speech synthesis.

  • Voice message recording and processing
  • Text-to-speech response synthesis
  • Multiple voice options and languages

Interactive API Documentation

Explore Sadeh's RESTful API with our interactive Swagger documentation. Test endpoints directly in your browser, view request/response schemas, and integrate with your applications.

  • Complete OpenAPI 3.0 specification
  • Interactive request builder and tester
  • Detailed schema documentation
  • Authentication endpoints

About Sadeh

Sadeh is an enterprise-ready AI assistant platform built with Flask. It delivers secure, context-aware conversations with advanced RAG capabilities, voice interaction, and comprehensive access control for organizations that need AI tailored to their data.
