Features

Conversational AI

Engage with multiple AI models through an intuitive chat interface. Have natural conversations with context awareness and history tracking.

Voice Capabilities

Record voice messages and get AI responses through text-to-speech synthesis. Support for multiple voices and natural language understanding.

Document Processing

Upload and process documents for Retrieval-Augmented Generation (RAG). Extract knowledge and get AI responses based on document content.

Role-Based Access

Comprehensive RBAC system for controlling access to pages, features, and AI models. Easily manage user permissions through the admin interface.

Robust Database

SQLAlchemy ORM with automatic migrations and seeding. Stores conversations, user data, permissions, and document indices efficiently.

RESTful API

Comprehensive API endpoints for all functionality including authentication, conversations, document management, and administration.
